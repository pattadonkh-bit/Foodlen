# NutriKid — ระบบเฝ้าระวังภาวะโภชนาการเด็กวัยเรียนจากภาพอาหารไทย

โครงงาน CS2569 / SCS2-16 สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น
**การประเมินพลังงานและสารอาหารจากภาพอาหารไทยด้วยเทคนิค Deep Learning เพื่อเฝ้าระวังภาวะโภชนาการของเด็กวัยเรียนบนเว็บแอปพลิเคชัน**

ผู้จัดทำ: ปิยพันธ์ แก้วเก็บคำ, พัทธดนย์ คำนัน · อาจารย์ที่ปรึกษา: ผศ.ดร.วชิราวุธ ธรรมวิเศษ

> ระบบนี้เป็นเครื่องมือเฝ้าระวังเบื้องต้น **ไม่ใช่การวินิจฉัยหรือคำแนะนำทางการแพทย์** ค่าโภชนาการและกฎคำแนะนำยังไม่ผ่านการตรวจสอบโดยผู้เชี่ยวชาญ
> (ชื่อ NutriKid คือชื่อที่แสดงบนเว็บ ชื่อภายในโค้ด แพ็กเกจ และตัวแปรตั้งค่ายังเป็น `Foodlen`)

## ลองใช้งาน (ออนไลน์)

- เว็บ: <https://foodlen-web.onrender.com> (ล็อกอินหรือสมัครสมาชิกผู้ปกครองที่ `/register`)
- ทั้งหมดรันบนแพ็กเกจ **ฟรี** (Render + Neon Postgres) จึง **หลับเมื่อไม่มีคนใช้ 15 นาที** เปิดครั้งแรกอาจรอ ~1 นาที และถ้าส่งภาพให้ AI ครั้งแรกแล้วขึ้นว่าเชื่อมต่อไม่สำเร็จ ให้รอสักครู่แล้วลองใหม่
- ข้อมูลเด็กต้องล็อกอินก่อนจึงจะเห็น แต่ยังไม่ผ่านการตรวจความปลอดภัยโดยผู้เชี่ยวชาญ **อย่าใส่ข้อมูลเด็กจริงจนกว่าจะทบทวนด้านความปลอดภัยและ PDPA**

## ทำอะไรได้

1. ลงทะเบียนเด็ก (ต้องมีการยินยอมจากผู้ปกครอง) แล้วประเมินภาวะโภชนาการด้วย BMI-for-age (WHO 2007)
2. ถ่ายภาพอาหารจากกล้องในเบราว์เซอร์หรืออัปโหลดไฟล์ → AI (ResNet50) จำแนกเมนูอาหารไทย 101 เมนู
3. ถ้า AI ไม่มั่นใจ (ต่ำกว่า 0.80) ให้ผู้ใช้ยืนยันเมนู หรือค้นหาเมนูเองจากรายการ 211 เมนู (รวมนม เครื่องดื่ม ผลไม้ ขนม)
4. เลือกสัดส่วนที่เด็กกิน → คำนวณพลังงานและสารอาหาร เทียบกับความต้องการต่อวัน แล้วแสดงไฟจราจรและคำแนะนำ
5. บันทึกประวัติมื้อ (แก้ไข/ลบได้) สรุปรายสัปดาห์ กราฟการเจริญเติบโต และสถิติรวม
6. แยกสิทธิ์: **ผู้ปกครอง** เห็นเฉพาะเด็กของตนเอง **ครู/นักโภชนาการ** เห็นภาพรวมทั้งห้อง จัดเรียงตามความเสี่ยง กรองได้ และส่งออก CSV

## รันในเครื่อง (ย่อ)

ต้องมี JDK 17+ และ Python 3.10–3.12 รายละเอียดเต็มอยู่ใน [demo/README.md](demo/README.md)

```bash
# 1) บริการ AI (พอร์ต 5000)
cd demo/yolo-service
py -3.10 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
run-ai.bat

# 2) เว็บ (พอร์ต 8080) เปิดอีกหน้าต่างหนึ่ง
cd demo
./mvnw spring-boot:run -Dspring-boot.run.arguments=--foodlen.seed-demo=true   # โหมดสาธิต: มีเด็กและบัญชีตัวอย่าง
```

โหมด `seed-demo` สร้างบัญชีสาธิตและข้อมูลจำลอง (รหัสผ่านอยู่ใน demo/README.md) **ห้ามเปิดบนระบบที่มีข้อมูลจริง**

## Deploy ฟรี

เว็บและบริการ AI อยู่บน Render (แพ็กเกจ free) ตั้งค่าไว้ใน `render.yaml` ส่วนฐานข้อมูลเป็น Neon Postgres (แพ็กเกจ free)
ตัวแปรลับ (รหัสผ่านฐานข้อมูล บัญชีครู) ตั้งในหน้า Environment ของ Render ไม่เก็บใน repo ขั้นตอนอยู่ในหัวข้อ Deploy ของ [demo/README.md](demo/README.md)

## ผลการทดลองโดยสรุป

| รายการ | ผล |
|---|---|
| จำแนกอาหาร 101 เมนู (ResNet50, ฝึกครั้งเดียว) | accuracy 92.30%, top-5 99.09%, macro-F1 0.893 บนชุดทดสอบ 13,433 ภาพ |
| เกณฑ์ความมั่นใจ 0.8 | รับอัตโนมัติ 77.7% ถูกต้อง 98.8% ต้องให้ผู้ใช้ยืนยัน 22.3% |
| โมเดล ONNX เทียบ PyTorch | ผลตรงกัน (10 จาก 10 ภาพ) ใช้ RAM น้อยกว่าราว 3–5 เท่า |
| ภาวะโภชนาการ (z-score) | ตรงกับการเทียบตาราง WHO ในโปรแกรม 300 จาก 300 ราย (ยังไม่เทียบเครื่องมืออิสระ) |

## ข้อจำกัดที่ควรรู้

- **ระบบไม่ประมาณปริมาณอาหารจากภาพ** ผู้ใช้เลือกสัดส่วนเอง ค่าพลังงานจึงเป็นการประมาณคร่าวๆ
- ข้อมูลโภชนาการมาจากตารางแคลอรี่ที่เผยแพร่ทางเว็บ (แหล่งทุติยภูมิ อ้างฐานข้อมูลสถาบันโภชนาการ มหิดล) ไม่ใช่ Thai FCD ต้นฉบับ
  บางเมนูเป็นค่าประมาณของผู้พัฒนา และสารอาหารหลักทั้งหมดเป็นค่าที่คำนวณจากเมนูที่คล้ายกัน ยังไม่ได้ตรวจกับผู้เชี่ยวชาญ
- เมนูเพิ่มเติม 110 เมนูที่ไม่มีใน AI ต้องเลือกเอง และฐานกฎคำแนะนำ/เกณฑ์ความเสี่ยงเป็นค่าเริ่มต้นของผู้พัฒนา
- ชุดข้อมูลภาพบางส่วนมาจากร้านเดียวกันทั้งชุดฝึกและชุดทดสอบ ผลกับร้านใหม่อาจต่ำกว่านี้
- ชุดทดสอบอัตโนมัติ `WebFlowTest` เขียนก่อนมีระบบล็อกอินและยังต้องปรับให้ล็อกอินก่อนเรียกหน้า
